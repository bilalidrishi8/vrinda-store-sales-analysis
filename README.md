# 🛍️ Vrinda Store SQL Data Analysis

## 📌 Project Overview

This project analyzes the **Vrinda Store Sales Dataset** using **PostgreSQL**. The goal is to answer real-world business questions, uncover sales trends, and generate actionable insights using SQL.

This project demonstrates SQL skills ranging from beginner to advanced, including joins, aggregate functions, window functions, CTEs, subqueries, and business reporting.
